# Winsock TCP Server

Учебный TCP-сервер на C (Windows, Winsock). Демонстрирует базовый цикл
работы с сокетами

## Что делает
- Создаёт TCP-сокет и привязывает к `0.0.0.0:8080`
- Переводит сокет в режим прослушивания (`listen`)
- Принимает **одного** клиента (`accept`)
- Читает данные (`recv`) и **возвращает их обратно** (`send`) — эхо
- Корректно закрывает сокеты

## Требования
- Windows
- Компилятор C: MSVC (Visual Studio) или MinGW (GCC)

## Сборка

MSVC:
    cl main.c ws2_32.lib

MinGW:
    gcc main.c -o server.exe -lws2_32

## Запуск
    server.exe

Сервер слушает `0.0.0.0:8080` и ждёт одного клиента.

## Проверка
    Панель управления → Программы → Включение компонентов Windows →
    галочка «Клиент Telnet» → ОК → перезапустить терминал.

    telnet 127.0.0.1 8080
    > hello
    hello
